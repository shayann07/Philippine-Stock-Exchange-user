# Philippine Stock Exchange - User App

This repository contains the **User application** for the Philippine Stock Exchange (PSE) mobile platform. The Android app enables end users to browse real‑time market data, manage their portfolios and execute trades securely from their mobile devices.

## Features

- **Real-time market data**: View up‑to‑date stock prices, trading volume, and market indices.
- **Stock search and watchlists**: Search for listed companies and maintain a watchlist of favorite securities.
- **Portfolio management**: Track your holdings, monitor gains/losses and view transaction history.
- **Trading**: Submit buy and sell orders directly from the app (integrated with broker APIs).
- **Notifications**: Receive alerts on price movements, order status and market news.
- **Secure authentication**: Support for user registration, login, and two‑factor authentication.

## Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and download dependencies.
4. Configure API endpoints, authentication providers and API keys in the appropriate configuration files.
5. Build and run the app on an Android device or emulator.

## Technologies

- Java / Kotlin for Android
- Android Jetpack components (LiveData, ViewModel, Navigation)
- RESTful APIs & WebSockets for real‑time data
- Gradle build system
